# 🎮 Playable Ad Builder

A powerful visual builder specifically designed for creating playable ad game mechanics and layouts. Design interactive game experiences with an intuitive drag-and-drop interface, professional animations, and export them as standalone HTML files optimized for advertising platforms.

## ✨ Key Features for Playable Ads

### 📱 Pre-Built Templates
- **5 Professional Templates** ready to customize
  - Tap to Collect - Classic collection game mechanic
  - Avoid & Reach - Navigate through obstacles
  - Puzzle Match - Match-3 style gameplay
  - Endless Runner - Fast-paced running game
  - Blank Mobile Ad - Start from scratch
- Templates include optimized animations and CTAs
- One-click loading with full customization

### 🎨 Visual Design Tools
- **Drag-and-drop interface** for easy element placement
- **Real-time canvas editing** with zoom and pan controls
- **Snap-to-grid** for perfect alignment
- **Multiple element types**: buttons, CTA buttons, targets, obstacles, shapes, text, and images
- **Visual property editor** for customizing every aspect
- **Layer ordering** system for precise control

### 🎬 Professional Animations
Built-in CSS animations perfect for playable ads:
- **Bounce** - Attention-grabbing vertical motion
- **Pulse** - Scale breathing effect
- **Shake** - Warning or error indication
- **Float** - Gentle up/down movement
- **Spin** - Continuous rotation
- **Glow** - Pulsing glow effect (perfect for CTAs)

### 🔗 Call-to-Action (CTA) Integration
- **Dedicated CTA button element**
- Link directly to App Store/Play Store URLs
- Pre-configured with glow animation
- Customizable text and styling

### 📱 Mobile-First Design
- **Mobile device preview frame** - See your ad in a phone mockup
- **Common ad size presets**: 800x600, 640x960, 320x480, 750x1334
- **Touch-optimized** export with proper mobile event handling

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## 📖 Usage Guide

### Quick Start Workflow

1. **Choose a Template** - Click "Templates" button
2. **Design Your Ad** - Drag and drop elements
3. **Add Animations** - Select from 6 animation types
4. **Add CTA** - Link to your app store
5. **Preview & Export** - Test and download HTML

### Pro Tips for Playable Ads

1. **Keep File Size Low** - Monitor estimated size (aim for <2MB)
2. **Mobile-First** - Use mobile frame preview
3. **Animations Add Engagement** - Use "glow" on CTAs
4. **Clear CTA** - Make download button prominent
5. **Test Interactions** - Always preview before export

## 📦 Export Format

Exported HTML files include:
- All CSS animations
- Touch-optimized events
- Score tracking
- Win/lose logic
- Mobile viewport settings
- Typical size: 2-10KB
